# Dirección visual V2.3

Referencia principal: Delivery Associates.

Principios aplicados:

1. Titulares de gran escala y mensajes cortos.
2. Fotografía humana y territorial como contenido, no decoración.
3. Bloques asimétricos con mucho aire y contraste.
4. Menos tarjetas homogéneas; más piezas editoriales y casos destacados.
5. Números compactos y legibles: evitar cifras monetarias que rompan la composición.
6. Información cuantitativa acompañada de explicación, fuente y contexto.
7. Testimonios como capa narrativa, marcados como ilustrativos mientras no exista fuente real.
8. Mantener negro/carbón, gris, blanco/crema y amarillo como acento.
