# Territorio Inteligente — Dirección visual V2.2

V2.2 no cambia los datos ni la lógica funcional de V2.1. Recompone la interfaz con un lenguaje editorial inspirado en Delivery Associates:

- jerarquía tipográfica extrema;
- navegación sobria sobre gris/carbón;
- amarillo como acento, no como relleno indiscriminado;
- secciones de gran escala y mucho espacio negativo;
- cards convertidas en piezas editoriales asimétricas;
- métricas tratadas como titulares;
- CTAs simples, lineales y con movimiento mínimo;
- módulos internos con número de producto grande como elemento gráfico;
- reducción de bordes y cajas de dashboard genérico;
- conservación de accesibilidad, responsive y reduced motion.

No se copiaron contenidos, assets ni componentes propietarios de Delivery Associates.
